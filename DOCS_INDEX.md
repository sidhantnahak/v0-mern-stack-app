## Before You Start

Make sure you have:
- Node.js v14+
- MongoDB installed
- 10 minutes of free time
- Your terminal open

## Quick Command Reference

```bash
# Install everything
npm run mern:install

# Start everything
npm run mern:dev

# Start just backend
cd server && npm run dev

# Start just frontend
cd client && npm run dev

# Build for production
npm run mern:build
```

## Support & Help

### If Something Breaks
1. Check the relevant troubleshooting section
2. Verify MongoDB is running
3. Try stopping and restarting servers
4. Check browser console for errors
5. Review server terminal output

### Common Issues
- Port already in use → See SETUP_GUIDE.md
- MongoDB connection error → See SETUP_GUIDE.md
- CORS errors → See SETUP_GUIDE.md

### Still Stuck?
- Review the relevant document thoroughly
- Check the issue description carefully
- Verify all prerequisites
- Make sure both servers are running
